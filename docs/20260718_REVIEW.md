| Component | Status | Notes |

### What is implemented

- `CrowEntity` — full entity with AI goals, data sync, GeckoLib animation
- `ScavengeGoal` — priority-based item pickup with satiation cooldown
- `SwarmDistressGoal` — retaliation and swarm combat modes
- `SwarmManager` — per-dimension coordination with escalation tracking, cleaned up on dimension unload
- `CrowNestBlock` + `CrowNestBlockEntity` + `CrowNestStateMachine` — full lifecycle
- `CrowNestSeekGoal` — BFS-based nest finding (32-block radius)
- `CrowSpawning` + `CrowNestFeature` — biome spawning and procedural placement
- Networking — `DistressPayload`, `ScavengePayload` with codecs
- Registration — entities, blocks, items, sounds, features
- `BlackFeather` item — registered with `minecraft:feathers` tag
- `BLACK_OIL_SUNFLOWER_SEEDS` crafting recipe — shapeless: wheat_seeds + coal
- Crow entity loot table — black feather + seeds drops
- `CrowNestStateMachineTest` — full lifecycle unit test
- `CrowNestBlockEntityTest` — NBT serialization contract tests

- ~~Client-side network handlers are **empty stubs**~~ → ✅ **FIXED** (2026-07-18) — visual/audio feedback implemented
- ~~`BLACK_OIL_SUNFLOWER_SEEDS` crafting recipe (absent)~~ → ✅ **FIXED** (2026-07-18) — shapeless recipe: wheat_seeds + coal → 2 seeds
- ~~Crow entity loot/drop table (absent)~~ → ✅ **FIXED** (2026-07-18) — 0-2 black feathers always; seeds on player kill

- Texture PNGs (`crow.png`, `crow_nest.png`, `icon.png` — absent)
- Mixins (both configs are empty)
- `getBreedOffspring()` returns `null` (by design — nest-based spawning)
- `onNonCrowDamaged` in SwarmManager is empty (by design)
