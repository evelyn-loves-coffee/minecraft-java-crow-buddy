# crow.png — Crow Entity Texture (GeckoLib Sprite Sheet)
# Path: assets/crowbuddy/textures/entity/crow.png

Dimensions: 64×32
Format: PNG with alpha channel
Transparency: Entire canvas starts transparent; only UV-mapped regions draw

UV Layout (both adult and baby share this texture):

  ┌────────────────────────────────────────────────┐
  │ 0-8,0-4     │ 16-36,0-10                       │ 32-44,16-22    │
  │ HEAD cube   │ BODY (5×6×8)                     │ TAIL           │
  │             │                                    │                │
  │ 0-4,8-10    │                                  │                │
  │ BEAK        │ 0-4,16-22                        │ 48-56,16-20    │
  │             │ LEFT/RIGHT WING (mirrored)       │ LEFT LEG       │
  │             │                                  │ 52-56,16-18    │
  │             │                                  │ RIGHT FOOT     │
  └────────────────────────────────────────────────┘

Detailed UV Regions:

  Head (cube 4×4×4):         UV [0,0]    → pixels 0-8,  0-4
  Beak (2×1.5×2.5):          UV [0,8]    → pixels 0-4,   8-10
  Wings (each 1×6×6):        UV [0,16]   → pixels 0-4,  16-22  (shared, mirrored)
  Body (5×6×8):              UV [16,0]   → pixels 16-36, 0-10
  Tail (4×2×5):              UV [32,16]  → pixels 32-44, 16-22
  Left/Right Leg:             UV [48,16]  → pixels 48-56, 16-20
  Left/Right Foot:            UV [52,16]  → pixels 52-56, 16-18

Color Notes:
  - Crow is predominantly black; use subtle shading/gradients for depth
  - Beak should be dark gray or black
  - Eyes need to be visible — white or light-colored pupils
  - Legs/feet should be gray or dark gray

Notes:
  - Adult and baby crows share this same texture; baby is just scaled down
  - Wing UVs are shared between left and right (right wing is mirrored)
  - Leg UVs are shared between left and right (right leg is mirrored)
