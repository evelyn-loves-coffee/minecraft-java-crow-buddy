# crow_nest.png — Crow Nest Block Texture
# Path: assets/crowbuddy/textures/block/crow_nest.png

Dimensions: 64×64
Format: PNG with alpha channel
Transparency: REQUIRED — edges and top opening must be transparent

Usage:
  - Block faces (all 6 sides via cube_all model)
  - Inventory item view
  - Dropped item entity

Content:
  The nest should appear as a cup-shaped structure made of twigs, mud,
  and grass. Since it uses cube_all (same texture on all faces), design
  it so it reads as a nest from any angle.

  Recommended approach:
  - Center of the texture: the nest body (twigs, mud)
  - Top portion: the opening of the nest (transparent center, rim around it)
  - Bottom portion: underside of the nest
  - Edges: transparent so the nest doesn't block view through it

Transparency Regions:
  - Top-center opening: transparent (where eggs/chicks will be rendered)
  - Corners and outer edges: transparent (nest sits within the block space)
  - The block has noCollision() and noOcclusion(), so transparency is key

Notes:
  - Programmatic geometry (eggs, chicks, hatching effects) overlays this
    texture via CrowNestBlockEntityRenderer (Phase 5, not yet implemented)
  - The transparent center area is where eggs and chicks will appear
  - Use natural browns, grays, and greens for twig/mud/grass materials
